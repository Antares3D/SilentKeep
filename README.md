SILENT KEEP

Stealth Game Prototype — Unreal Engine

A 4-level stealth game prototype focused on AI perception, Behavior Trees, gameplay systems, level progression and interactive world design.

Features

- Enemy AI with patrol, sight and hearing
- Behavior Trees + Blackboard
- AI Perception
- Last Known Location
- Search Location
- Stealth takedowns
- Key/door interaction system
- Persistent level progression
- Quest/objective system
- Health and consumable system
- Global castle alert system
- Multiple interconnected levels


Technical Highlights

- Reusable Blueprint architecture
- Custom Behavior Tree Tasks
- Game Instance state management
- Modular interaction systems
- Animation montages and notifies
